Drop the meet's scoreboard text file (the tab-delimited *_SCB.TXT you send to
the timing system) in this folder. No restart needed - the scoreboard server
picks up new, changed or removed files within a second or two.

Used as a backup source for event titles, swimmer names and entry times (PB
badges) when the Gen7 console feed doesn't have them (e.g. session-2 events
never send a title).

Tip: keep only the current meet's file(s) here. Files are merged, so an old
meet's file with the same event numbers can show the wrong names/titles.

This folder is NOT served over the web and NOT committed to git - safe to
drop files with swimmer names/ages in here.

Files named in .drive-synced.json were downloaded automatically from the
Google Drive Meets folder (see meet.html) and are replaced when you pick a
different meet. Files you add yourself are never touched.
