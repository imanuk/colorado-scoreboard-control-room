# Configuration

Everything here is optional. The program starts with sensible defaults; you only add a file when you
want to change something. **Your own copies of these files are git-ignored** - only the `*.example.json`
files (and `counties.json`) are part of the repository, so you never commit your club's details.

| File | What it does | Start from |
|---|---|---|
| `drive.json` | Which shared Google Drive folder holds your meets (`rootFolderId`), and how to find the files in it. Needed for the meet picker. | `drive.example.json` |
| `stream.json` | Your YouTube channel handle (`channelHandle`), the link viewers watch (`viewerUrl`) and the intro line for the stream description. Also written by the control room when you save these. | `stream.example.json` |
| `network.json` | Friendly name (`scoreboard.local`), extra ports, live-view limits, and whether Go live / Stop may be used from another device (off by default; see [docs/NETWORK.md](../docs/NETWORK.md)). | `network.example.json` |
| `qualifying.json` | Which qualifying-time files to compare swimmers against (CT / RT / NT badges). Off until you import some. | `qualifying.example.json`, then [docs/QUALIFYING.md](../docs/QUALIFYING.md) |
| `clubs.json` | Club code -> county / region, generated by `scripts/import-clubs.js` from the club database. Not shipped. | run the import script |
| `clubs.local.json` | Your own additions to `clubs.json`; they win over it. | hand-written |
| `counties.json` | County code -> county name (used by the club import). Shipped; edit if a name is missing. | - |
| `obs.json` | Names OBS must have: `scene`, `cameraInput`, `cameraDeviceName`, `minDiskGB`, `expectWidth/Height/Fps`. | see `server/startupChecks.js` |
| `audio.json` | `{"alwaysMuted": ["Input name"]}` - extra OBS inputs to keep muted. | - |
| `tv.json` | `{"display": "...", "scene": "..."}` - which external display is the TV, and which OBS scene to project on it. | - |
| `live.json` | Settings for the live heat sheets (gaps between heats, report lead...). Written by the admin page. | the admin page |
| `publish.json` | The address and secret key for publishing live heat sheets to a web host. Made by `scripts/build-remote.js`. **Secret - never commit.** | the build script |
| `selected-meet.json` | The meet you last chose (so an automatic restart keeps it). Written by the program. | - |
