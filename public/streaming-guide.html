Before the meet - load swimmer names

  1. Set up the Gen7 console for today's meet
  2. In Meet Manager, set up the connection to the Gen7Meet Manager's scoreboard/timing-console connection settings, pointed at the Gen7.
  3. Export the scoreboard names file from Meet Manager, copy it to a USB stickUsually via USB stick, per the connection set up above.
  4. Load that file into the Gen7 from the USB stickExact menu/steps on the Gen7 still need double-checking next time you do this - update once confirmed.
  5. Confirm names are showing on the Gen7 console itself before relying on them over RS-485If they're not on the console, they won't come through the scoreboard app either.
  6. Make sure the meet's scoreboard file is in the shared Google Drive meet folderMeets/<meet>/reports/…_SCB.TXT (and the DLinkHSL files). The start icon lists the meets and loads the newest; Choose meet shows what each contains and flags anything missing.

Going live

  1. Set up the kitCharger in, USB ethernet adapter in, HDMI to the TV (TV on), GoPro plugged in by USB-C and switched on (USB Connection = GoPro Connect).
  2. Double-click Start Stream Day on the DesktopIt starts the scoreboard, asks which meet (Enter takes the newest), gets the GoPro ready, opens OBS and opens the control room. If it says OBS needs a restart once, say yes (only when you are not live).
  3. Wait for the green ticks in the control roomFix anything red - each one says what to do. Amber is worth a look but won't stop you. "Re-run checks" repeats them.
  4. Check the preview and the TVThe "On air" picture should be live and framed properly, and the Samsung showing the scoreboard (Scoreboard TV scene projected to it).
  5. Paste the YouTube live link into "What viewers see" (first time only)It is remembered. It shows what viewers actually receive, 15-30 seconds behind, muted.
  6. Press Go live and confirmStarts the stream (to Restream.io, which fans out to YouTube) and the recording together; it waits to see the stream actually hold before saying it worked.
  7. Confirm the viewer panel shows the broadcastIf it doesn't after a minute, check the Restream dashboard - every destination it fans out to.
  8. At the end press Stop and confirmIt shows where the recording was saved. Heat chapter markers are added to the recording automatically.
Streaming is via Restream.io (OBS streams to Restream, which handles distribution from there) - not directly to a single platform, so double-check the Restream dashboard if a viewer reports nothing showing.
